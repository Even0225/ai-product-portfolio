These are modified subsets of Noto Sans SC, limited to the weight range 400–700.
They retain the original font name and copyright/license metadata. No Reserved
Font Name is used as the primary font name. The fonts remain under SIL OFL 1.1.

ui: all characters in the app's top-level HTML/CSS/JS plus Latin/punctuation.
common: remaining GB2312 characters supported by the source, excluding ui.
The generated CSS uses disjoint unicode-range values to load only needed subsets.
Characters outside this coverage use the CSS system font fallback.

Build helper: runtime/build-interface-fonts.py (FontTools, build time only).
build-info.json records source SHA-256, coverage count and output sizes.
The app needs no Python, package install, external font host or font installation.
